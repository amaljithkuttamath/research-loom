# Focused questions

## Maintainer decision

Which AI coding agents merit a controlled trial for issue fixing in small Python repositories, based on evidence about fix correctness and maintainer review effort?

This question supports candidate selection rather than an unsupported universal ranking. Evidence about tool access, cost, installation, and privacy informs feasibility but does not replace the two outcome measures.

## Empirical study

Under comparable issue conditions, how does using an AI coding agent change total maintainer effort per accepted correct fix compared with working without an agent?

Review effort is a prespecified component of total effort. Correctness, acceptance rate, failed attempts, and elapsed completion time should be reported alongside effort so time savings cannot be attributed to dropping difficult tasks or accepting weaker fixes.

## Unresolved operational definitions

- What qualifies as a small Python repository and an eligible issue?
- Which agent versions, configurations, budgets, and intervention policies are being compared?
- What independent validation establishes a correct fix?
- Who counts as a maintainer and how is effort measured consistently?

These are protocol details to resolve before a local trial or study, not additional research goals.
