# Observed behavior in one exploratory treatment

Loaded the actual bundled Research Loom orchestrator, interview, narrow, search-plan and search instructions and configuration/node/paper-data references. Initialized this isolated project using project_config.py and resolved its bundled defaults. No other agent artifacts were examined.

The assistant used two clarification rounds after the initial broad request, followed up on “reliability,” distinguished the maintainer decision from the empirical-paper goal, proposed one question per goal, and received simulated confirmation before preparing concrete source/query plans. It preserved the empirical goal and separated protocol preparation from answering the empirical question. The final scripted turn explicitly removed live search from scope.

Produced an interview brief, agreed question records, and six planned branches containing twelve initial queries. The source/interface verification requirement is deferred until execution because no live searches are authorized by the final simulated turn. No source findings, agent ranking, measured effects, or empirical results were invented. State marks interview, narrowing, and planning complete; it does not mark searching complete. The source ledger has planned searches and empty papers/claims arrays.

All later user turns are visibly labeled simulated in the transcript. The week allocation, screening cap, effort framing, and operational choices are proposed planning decisions, not extra user answers. Scope thresholds and participant feasibility remain open.

This is a single exploratory matched treatment run. It does not establish statistical improvement, causal skill effects, reproducibility across models, or superiority to a control. Comparison must be performed by the parent evaluator against the independently generated control.
