# Research Search

Read the branch plan and [references/evidence.md](references/evidence.md). Use available browsing, connectors, or documented APIs to execute queries. A chosen source is not proof that access exists. If direct access is blocked, report it and propose an accessible alternative; label site-limited web searches as such, not as direct database searches. Do not bypass access restrictions.

Record exact query, source/interface, date, filters, accessible coverage, and selection rationale. Return a source ledger with verified metadata/identifier, access level, supported findings, relevant locator, limitations, and goal/branch provenance. Discovery snippets are leads, not full-text evidence. Note corrections, retractions, and publication/version status when ascertainable.

Refine queries using observed terminology; record refinements and why. Follow references/citations when useful. Deduplicate within the branch without erasing original hits or version information. Return unresolved gaps, access failures, and next-query suggestions. Do not claim exhaustive coverage unless the documented protocol and actual execution support it.

When invoked by Research Loom, return paper/search/claim records matching [the shared paper data contract](../research-loom/references/paper-data.md). The orchestrator merges and validates them.
