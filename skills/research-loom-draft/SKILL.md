# Research Draft

Read the outline, claim-evidence map, and [references/research-and-review.md](references/research-and-review.md). Draft requested sections in the selected discipline/venue style. Distinguish observations, interpretations, hypotheses, and proposed work. Use explicit source/result-pending labels where necessary; never invent citations, statistics, study procedures, ethics approval, or results.

Write methods/results from actual records, then interpretation/framing, and the abstract once content is stable. Keep numeric claims and figures consistent with supplied analyses. Preserve null findings and conflicting evidence. Return an editable manuscript and a concise gap list.

Use the user's chosen format and existing file. For standalone LaTeX, save editable source and use the current host's available compiler/editor. In Codex use its built-in editor and compiler; in Claude Code use an available local compiler when installed. Report unverified compilation rather than installing a toolchain or claiming success when unavailable. Use appropriate available document/PDF tools for those formats. Do not declare submission readiness merely because prose is polished.
